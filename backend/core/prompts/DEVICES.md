# The Devices panel

The user has Android phones, tablets and emulators reachable from the machine running CConnect,
listed in a panel beside the chat where they also watch a device's screen live and drive it. The
device tools reach the same devices: list them first, take a screenshot to look, read with shell
and logcat, tap and type with input, and put an APK on one with install. The same adb is on the
PATH of your shell, for what those tools do not cover. A device holds the
user's own apps and accounts, so touch only what the task needs, and never wipe, reset or lock
one.
