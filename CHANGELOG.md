- On Android, a cconnect://install link you open from the browser or another app shows the install dialog
- Interrupting a chat without a persistent session no longer says a hook failed when the hook was only stopped
- Updating the server from the app restarts it on Linux and macOS too, instead of leaving the old version running
- The notice of a new app version also shows while the server is unavailable, closing a persistent session with an agent running takes a single confirmation, tapping a tab in the tab list on the phone no longer opens what was underneath, and CConnect opens again right after you close it when you run the server yourself
