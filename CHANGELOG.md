- The Claude screen lists its sections in a column on the side, like Settings, grouped into Extensions and Customization
- Styles, Commands and Agents show the ones Claude Code brings, your plugins' and your own: create, edit or delete yours, for you or for the project you pick, and choose the style Claude answers in
- Skills lists the ones an MCP server offers too, with their files
- Code mode, in Generation, has Claude write a program that calls its tools, MCP ones included, instead of calling them one by one
- `/reload-session` restarts the chat's Claude Code so changes to hooks and settings apply, at once or when the turn ends, and Claude can ask for it too
- The output style, the instruction files and the task tools live in Claude Code's own settings, so what you set in the CLI is no longer replaced
- With a project locked in the environment, Ctrl+K, the project prompt and the Claude screen only offer that project, and a chat can no longer be moved out of it
- Devices no longer keeps a Wi-Fi phone listed after its port changes, a phone's screen shows at once when you come back to its tab instead of loading forever, the command menu only shows while the composer has the cursor, a remote MCP server you just added offers its sign-in right away, a limit window leaves the usage once it resets, and Claude no longer takes a background task's notice as something you wrote
