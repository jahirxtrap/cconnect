- A chat can keep its session running while you have it open, off by default under Persistent sessions in the Server settings: Claude answers without starting up first, a command it leaves running keeps working between your messages, and the session closes by itself a while after the last device leaves the chat, once nothing is left running
- Each session holds about 400 MB of memory while it lives, so you choose how many chats keep one at a time — past that, the oldest idle one closes — and how long it waits for you to come back
- A persistent chat carries a flame in the list and in its header, where one tap closes the session, and what reaches it between your messages — a message from another session, a command finishing in the background — appears as it arrives instead of the next time you open the chat
- Closing the right panel on the phone no longer throws away what it had open: the project you picked, the folders you unfolded and the note you were writing are still there when you open it again, the same as on the desktop, and going back closes it instead of walking you out of the project first
- Auto-rename, the commit message Claude writes for you and the quick chat work again
- The Claude screen lists a project's AGENTS.md among its memories, next to its CLAUDE.md
- A server where Claude Code turns Bypass down — running as root, or under a policy that disables it — stops offering it and falls back to Auto instead of failing on every message
- Opening or closing a thinking block or an edit no longer nudges the chat by a pixel, the header a long block pins at the top looks the same as the block itself, and the shortcuts for tabs and the address bar use Ctrl in the browser again
