- A new look across the app: rounded panels, menus and dialogs, and on the desktop Settings, Claude, Monitor, Shared and Notes open beside your chats instead of covering the window
- Theme picks a light and a dark theme among two dozen, from Claude and GitHub to Dracula and Nord, with the terminal colours chosen apart
- Chat background puts the logo or a picture of your own behind the conversation, and Font chooses the typeface for text, code, symbols and emoji
- Themes, fonts and backgrounds come as .ccpack packs, installed from Packs in the Client settings or opened from the chat, Shared or any app on Android
- Claude can hand a task to another AI — a model, another of your accounts or an agent like Codex — set up under Delegation in the Server settings
- What runs in the background is listed under Running in the chat's header, each task with a button to stop it
- A persistent chat stays open while something still runs in the background, and waits five minutes after the last device leaves instead of two
- The context ring shows your session and weekly limits as they move, and how long the cache has left
- A slow response says why it is waiting and when it tries again, instead of only that it is taking longer than usual
- Each tool carries its own icon in the chat, and a run of reads or searches folds into one line
- Mods are on by default, and Reload plugins under ⋮ in the Mods view brings in what you changed without leaving the chat
- The app comes in ten languages
- A referenced file downloads without the security key, a chat can be deleted while it works, and reconnecting a device no longer restarts the session on another account
- This version needs server 2.0.0, which the Update button in the Server settings installs

> [!NOTE]
> The web version is available at https://app.cconnect.dev/
