- The backend installs itself: one line puts the `cconnect` command on your PATH, and from it you serve, expose, stop, update and ask where things are. A git checkout is the same code with the same commands
- Its data lives in `~/.cconnect/data`, and `cconnect migrate` brings over what a checkout had — settings, accounts, the shared folder, the trash and the keys — without touching the original
- The desktop app can start either one: choose whether the local server comes from the installed command or from a repository and Python
- The server's own row looks up the release for an installed server, and updates it from the app when the app is the one running it
- A file Claude hands you arrives as its own block in the chat instead of a path it had to write out by hand: every file named and ready to open, save or save all of them into a folder you pick, and it is still there when you reopen the chat
- Opening a file no longer drags you back to the change you were reading, and separators read the same everywhere

> [!NOTE]
> The web version is available at https://app.cconnect.dev/
