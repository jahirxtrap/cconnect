- Redesigned interface across every screen — a new type scale, buttons, dialogs and menus, the chat composer gathered into a single panel, and a reworked file manager
- Give each environment its own colour, so you can tell servers apart at a glance; it can also follow the system accent
- Pick the Claude account per chat from the composer bar, remembered per environment — leave it on Server and the backend resolves it every turn, so changing the default applies without reconnecting
- Sort files by name, date, type or size from a submenu, with the direction as its own switch instead of a second tap on the field
- Images in the chat render as tiles in a grid that reserves its space, so the conversation no longer jumps while they load
- Blockquotes opening with `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` or `[!CAUTION]` render as alerts with their own icon and colour
- Paste into the SSH terminal with Ctrl+V
- The account list loads instantly instead of taking up to 14 seconds and sometimes coming back empty
