- A `/loop` or anything Claude schedules keeps running after you close the app, instead of stopping with the chat, and what it asks Claude shows in the chat as Scheduled message
- A permission says why Claude Code asks for it, such as the hook or the rule behind it
- Rewind tells you when a terminal command changed files it cannot put back, and when some files could not be restored

- An account on a provider with Complete or Standard starting context gets Claude Code's whole prompt
