- Claude now asks with interactive forms in the chat, with choices, text fields, toggles and notes, instead of asking in plain text
- Longer questions arrive as pages you move through, and a note can be added without mixing it into the answer
- Replies can carry galleries, audio, PDFs and live previews, and Claude can draw blocks with bars, text and media
- Asking what the session is spending draws the plan usage in the chat
- Claude compacts the conversation when you ask it to
- Messages written while Claude works are kept by the server, so they survive a reload and read the same on every device
- Opening a conversation no longer flashes, the one you were reading stays in place until the new one is ready
- Moving between tabs keeps the conversation where it was instead of showing the start of it for a moment
- The restart button now works on Linux and macOS, not only on Windows
- A plugin dialog can be closed while it is working, and closing it cancels the action
- The chat stops notifying again for messages replayed after a reconnect
