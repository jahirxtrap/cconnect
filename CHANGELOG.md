- A message written while another window or device sits on the same conversation no longer looks sent without reaching the server
- The chat toolbar shows the real model, effort and permission names when the server answers late, instead of raw identifiers
- The local server no longer opens a console window on Windows, and its dialog shows the local address, the public one and the token
- Switching to the other build looks for the installer when you press it and downloads it with progress you can cancel
- On Android that download installs through the system installer, asking for permission when it is missing
- An installer that is no longer on disk stops leaving a dead install button behind
- Links open in the browser instead of inside the app
- Closing the current tab on a phone closes the tab switcher and leaves you in the conversation that takes over
- A numbered list follows its own order instead of repeating the numbers written in the text
- Copying a list keeps the bullet or number on the same line as the item
- The Android download is a quarter of the size it was
